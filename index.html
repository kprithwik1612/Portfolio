    Featured Work

    👁️
    LiDARVLMFusion
    LiDAR–Vision Fusion with VLM

    Designed and implemented a modular pipeline that injects LiDAR geometry into a frozen Qwen2-VL model to improve scene reasoning in autonomous driving. Evaluated on nuScenes-mini with controlled binary QA tasks to measure geometry-sensitive reasoning improvements.

    🪁
    🏆 Publication CAD3D Printing
    Flapping Wing UAV — Modular Powertrain

    Prototype Flapping Wing UAV with a swappable powertrain module. Awarded the Best Paper Finalist at IEEE ICMA 2024, Tianjin, China.

    View Paper
    STM32OpenCV MediaPipeC++
    Gesture Controlled Robotic Arm

    Real-time robotic arm manipulator integrating STM32 microcontroller with OpenCV and MediaPipe hand tracking. Achieved 95% gesture recognition accuracy with precise motor control over UART.

    PPOPyTorchAutonomous Driving
    Deep RL for Autonomous Driving

    Vision-based autonomous driving pipeline using Proximal Policy Optimization (PPO) for policy learning in simulated environments.

    PyTorchFixMatchSemi-Supervised
    Semi-Supervised Learning (FixMatch)

    Implemented FixMatch from scratch in PyTorch, achieving competitive benchmarks on CIFAR-10 and SVHN with limited labeled data.

    ROS2PythonRVIZGazebo
    A* Path Planning for TurtleBot3 Obstacle Avoidance

    Implemented an A*-based global path planner on a TurtleBot3 using ROS2 to autonomously navigate to defined goals while avoiding obstacles in a Gazebo simulation.

    UWB RTLSIMU FusionGPS-Denied

    Autonomous MAV deployment in GPS-denied environments. UWB RTLS fused with IMU for state estimation and velocity obstacle-based collision avoidance for UTM.
